Design, governance & evaluation

Architecture

Orchestrator → six expert stages → audit trace → human review. The report describes all stage contracts, taxonomy, SLA calculations and limitations.

Inference modes

This single-file HTML demonstration runs locally without AI API calls. The separate Streamlit application enables three specialist Gemini calls for triage, resolution/communications and independent QA.

Testing

Sixteen pytest checks have passed for the shared Python deterministic engine; that test result does not validate this HTML implementation or live Gemini output.

Privacy

All included customer names and cases are fictional. Avoid using sensitive business data without proper authorization and governance.

Policy boundaries

Risk points are heuristic. Deadline indicators are calendar-hour calculations, not real response event logs or contractual SLA judgments.

Human accountability

Review approvals are kept in browser memory for this session only. No messages are transmitted; nothing is persisted after closing this file.
